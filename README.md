# trmx-requests 🚀

A lightweight, pure-Python HTTP client designed specifically for **Termux** environments. It drops heavy binary dependencies (like Rust compilers or `cryptography`) to ensure lightning-fast installation and smooth HTTP requests on Android devices.

## ✨ Features
* **Zero Binary Dependencies:** No Rust or C compilers needed during installation.
* **Lightweight & Fast:** Handles `GET` and `POST` requests seamlessly.
* **Termux Friendly:** Smooth execution under modern Python environments (including Python 3.13+).
